## Features

| | |
|:--|:--|
| 🔎 **Explore** | Search and filter schemes by category, department and benefit |
| 🧭 **Find my schemes** | 5-step questionnaire with transparent eligibility matching |
| 🤖 **AI assistant** | Ask about schemes in plain language |
| 🔖 **Saved schemes** | Shortlist schemes to revisit later |
| 🌐 **Bilingual** | English and ಕನ್ನಡ toggle |
| 🔒 **Private** | Your answers stay in your browser |

</div>

```bash

cd Namma-Yojane-AI-scheme-Finder
npm install
npm run dev
```
